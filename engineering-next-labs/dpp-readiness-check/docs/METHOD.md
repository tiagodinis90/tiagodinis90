# Method and limitations

The rule file is versioned and distinct from the product record. Each rule defines a key, required/optional flag, type and whether an HTTPS evidence reference is required. Output lists missing fields and missing evidence per key.

This schema is a **synthetic illustration** of data hygiene and cannot certify compliance with ESPR. Regulation (EU) 2024/1781 provides a framework, but product-specific delegated acts determine detailed passport requirements. A URL is not verification of the linked evidence; example.org data is fictional. No network requests or data export occur.

Official source: [Regulation (EU) 2024/1781](https://eur-lex.europa.eu/eli/reg/2024/1781/oj/eng), particularly Articles 9–11 and Annex III.
